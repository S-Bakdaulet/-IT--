# ИИ-помощник с языковой моделью (Gemini) — настройка

Чат работает в двух слоях:
1. Встроенная нейросеть в браузере (MiniLM) + правила — работает всегда, без ключа.
2. Языковая модель (LLM) на сервере — включается, если задан ключ. Ключ только в переменных окружения, в коде и на GitHub его нет.

## Railway (рабочая ссылка)
1. Получить бесплатный ключ: https://aistudio.google.com/apikey
2. Railway → ваш сервис → **Variables** → добавить:
   - `GEMINI_API_KEY` = ваш ключ
   - `ALLOWED_ORIGINS` = `https://s-bakdaulet.github.io` (нужно, чтобы чат на GitHub Pages мог обращаться к серверу; уже добавлен по умолчанию)
   - необязательно: `GEMINI_MODEL` (по умолчанию `gemini-2.5-flash`)
3. Дождаться перезапуска. Проверка: `https://web-production-1842ea90.up.railway.app/api/ai/status` → `"llm": true`.

## Локально
```
set GEMINI_API_KEY=ваш_ключ        (Windows CMD)
$env:GEMINI_API_KEY="ваш_ключ"     (PowerShell)
python app.py
```
Открыть http://127.0.0.1:5000

## Другой провайдер (OpenAI-совместимый, например Groq)
`LLM_API_KEY`, `LLM_BASE_URL=https://api.groq.com/openai/v1`, `LLM_MODEL=llama-3.3-70b-versatile`

## Если ключа нет или сервер недоступен
`/api/ai/status` возвращает `"llm": false`, чат автоматически использует встроенную нейросеть. Ничего не ломается.

## Защита
Лимит 12 вопросов в минуту с одного адреса и 400 в сутки всего; ключ не уходит в браузер; в запрос к модели попадают только вопрос, данные сайта и последние реплики.
Никогда не вставляйте ключ в код и не публикуйте его в чате.
