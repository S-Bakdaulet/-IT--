О нашем каталоге

Данный проект создан для помощи студентам и начинающим специалистам в выборе будущей профессии в сфере информационных технологий.

Что мы предлагаем

Понятный обзор популярных направлений, чтобы вы выбрали путь осознанно, а не наугад.

🧭

Помощь в выборе

Описание каждой профессии: чем занимается специалист, какие навыки нужны и какой уровень дохода можно ожидать.

⚖️

Сравнение и тест

Сравните до трёх профессий в одной таблице или пройдите короткий тест и узнайте, какие направления ближе к вашим склонностям.

🗺️

Дорожные карты

Для каждой профессии есть пошаговый план обучения: с чего начать, что изучать дальше и что положить в портфолио.

🎓

Запись на курс

Оставьте заявку на выбранное направление, и мы свяжемся с вами в удобное время.

Как это работает

Четыре шага от интереса до начала обучения.

  1. Изучите каталог. Откройте карточки профессий и сравните их между собой.
  2. Выберите направление. Посмотрите зарплаты, требования и дорожную карту.
  3. Оставьте заявку. Укажите имя, телефон, курс и удобное время для звонка.
  4. Начните обучение. Мы свяжемся с вами и расскажем о старте группы.

Технологии проекта

Сайт состоит из трёх частей: интерфейс, сервер и база данных.

🖥️

Интерфейс

HTML5, CSS3 (Grid, Flex, адаптивная вёрстка, тёмная тема) и JavaScript без сторонних библиотек.

HTMLCSSJavaScript
⚙️

Сервер

Python и Flask: приём заявок, проверка данных, защита от спама, API для админ-панели и экспорт в CSV.

PythonFlaskREST API
🗄️

База данных

SQLite: таблица CourseRequests с именем, телефоном, курсом, уровнем, статусом и временем заявки. Просмотр через DBeaver.

SQLiteSQLDBeaver

Планы развития

Что можно добавить в проект дальше.

  1. Переключатель языка. Версия сайта на казахском языке.
  2. Уведомления. Сообщение в Telegram при каждой новой заявке.
  3. Размещение в интернете. Flask-сервер в облаке, сайт на GitHub Pages.
  4. Личный кабинет. Избранные профессии и прогресс по дорожной карте.

Учебный проект. Все цифры зарплат ориентировочные.
